# Scoring spec workbooks

One Excel workbook per database technology. Each workbook documents the full 100-point health-score model: pillars, subcategories, points, criticality gates and every metric, with the SQL that measures the value (Anchor SQL column) and the provenance of its threshold (Rationale column).

**Audience:** database specialists reviewing the scoring without reading JavaScript. Open in Excel, use the General tab's subcategory list, and drill into any metric. The Measurement column says where each measurement is defined: the Anchor SQL column, the scoring policy for engine-derived metrics, or a manual entry, and names any other collection source (Zabbix, Worker).

## Regeneration

```bash
npm install                                 # installs exceljs
npm run generate-scoring-spec              # writes 6 xlsx + this README, from this repository alone
```

`npm run generate-scoring-spec:internal` builds the internal set instead: it adds per-metric links into the private collector repository, needs a checkout of it next to this one, and writes to `docs/scoring-spec-internal/`, which git ignores.

Generated by `scripts/generate-scoring-spec.js`. Do not edit the XLSX files by hand: re-run the generator.
